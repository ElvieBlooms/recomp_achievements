# Recomp Achievements

## About
Recomp Achievements is a Gen1Recomp mod that is inspired by RetroAchievements and tries to bring some of that experience to your games. Instead of connecting to RetroAchievements like an emulator would, it instead stores a list of their achievements locally and allows you to earn supported achievements using independently written unlock conditions from Gen1Recomp's events and game state. Those earned achievements are then designed to sync through the save sync feature of G1R so you can keep them between your devices and play sessions.

## Planned Features
 - Bundled reference catalog of published RetroAchievements achievement metadata
 - A menu to both view your earned achievements and see the ones you still need.
 - Save sync through G1R
 - First-class mod support for adding achievements or custom lists. They'll be able to register achievements and report progress through our public achievement API.
 - In-game pop-ups and an optional sound when "achievement get"
 
## Development Status
This is in active development but it's early days. I'm using the modding process to learn how to code and am committed to writing this entirely by hand. My current plan is to start with Gen 1, build the base and core functionality and then expand to gen 2 and gen 3 in later phases.
