# Recomp Achievements

Achievements for every game Gen1Recomp plays: Red, Blue, Yellow, Gold,
Silver, Crystal, Ruby, Sapphire, Emerald, FireRed and LeafGreen. The lists
are the ones RetroAchievements publishes (1003 entries); every check is this
mod's own, written for Gen1Recomp. Unlocks are saved in your game, so they
follow Save Sync. Nothing goes online.

An unofficial fan project, not affiliated with RetroAchievements. Unlocks
here don't count on retroachievements.org.

## Install

In the launcher, **MODS > Import mod .zip** (or **Find mods**), then enable
it for the games you play. Gen1Recomp 0.3.97 or newer. Open the START menu
and choose **TROPHIES** (**TROPHY** in Gen 1 and Gen 2).

## Online scores

Want your score on the leaderboard without copying it out? Install the
**Recomp Achievements Online** add-on as well. It's a separate download so
this mod stays offline unless you choose otherwise.
