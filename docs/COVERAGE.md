# Coverage: official RetroAchievements sets

Generated by `tools/gen_coverage.lua` from `rules/gen1_official.lua` and the
bundled catalogs. Titles and descriptions are RetroAchievements metadata,
credited to RetroAchievements and each achievement's author. The detection
logic is this mod's own.

- **How**: *save state* is read from the save, so an existing save is
  credited when it loads. *event* reacts to something happening in play.
  *session* follows a run within one play session; loading a save resets
  it, which is how "without resetting" is enforced.
- **Old saves**: whether a save made before installing the mod gets credit.
- **Exact** means the check matches the RA description. **Local reading**
  means it is this mod's closest reading of it, explained in the note
  (also shown in game on the achievement's ABOUT page).
